## ZSH Auto Activate Python VENV

### Installation

```bash
git clone https://github.com/peppy0510/zsh-auto-activate-python-venv.git ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-auto-activate-python-venv
```

```bash
vim ~/.zshrc
```

```bash
plugins=(
    zsh-auto-activate-python-venv
)
```
